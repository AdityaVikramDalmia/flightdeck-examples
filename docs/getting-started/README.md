# Getting started

This public reference collection has **11 independent tool repositories exposing
13 command-line utilities**, plus the companion examples repository. Agent File
Guards contributes three utilities; each other tool repository contributes one.
The repositories are licensed under Apache-2.0 and deprecated for new Claude Code integrations as of 2026-09-22.

- [Checkouts and prerequisites](checkouts.md): remote names, local directory names, and required versus optional checkouts.
- [Run the examples](recipes.md): the core workflow and separate synthetic recipes.
- [Architecture](../architecture/README.md): what the tools' results establish.
